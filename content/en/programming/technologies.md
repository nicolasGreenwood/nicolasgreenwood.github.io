## WHAT I USE:
{.highlight-black .animate-box .grid-col-1-5}

**For design:**
I use Figma for prototyping, Inkscape for illustration/logo design
{.animate-text .grid-col-1-2}

**For development:**
Static frameworks: Hugo, Astro, Eleventy, Jekyll 
CSS: TailwindCSS, Sass, Bootstrap5, Bulma, plain CSS (for small projects)
JavaScript: Vanilla JavaScript (for most projects), AlpineJS, familiar with NodeJS environments and working with NPM packages

I offer integration with git-based CMSs including TinaCMS, SveltiaCMS, PagesCMS, and Keystatic as well as guidance on local git-based content authoring with markdown documents
